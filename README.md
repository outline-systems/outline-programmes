# Outline Programmes

A generic programme planning and Gantt scheduling tool. The application is a standalone `index.html` file and requires no build step.

## Use

Open `index.html` locally or enable GitHub Pages for a hosted version. Edit the `phases` data near the bottom of `index.html` to customise the programme phases and tasks.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
